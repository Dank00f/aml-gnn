## Какие скриншоты ещё нужно снять вручную

| Нужно | Что должно быть на изображении | Подпись |
|---|---|---|
| Главная страница | Upload form до выбора файла | «Главная страница загрузки транзакционного CSV» |
| Процесс обработки | Progress/SSE состояние до завершения | «Отображение прогресса обработки файла через SSE» |
| Общий граф | Граф после завершения без фильтров | «Построенный транзакционный граф» |
| Risk filter | Граф при `risk score >= 0.7` | «Фильтрация графа по риск-оценке» |
| Детали узла | Открытая правая/боковая панель выбранного account node | «Детали выбранного счёта и связанные транзакции» |
| Транзакции узла | Список входящих/исходящих операций и раскрытая карточка операции в detail panel | «Детали связанной транзакции выбранного узла» |
| Cycle pattern | Подсвеченные cycle alerts | «Обнаруженный циклический AML-паттерн» |
| Fan-out/transit | Подсвеченный fan-out или transit | «Пример fan-out/transit паттерна» |
| Clusters metadata | Вкладка кластеров и metadata | «Кластеризация графа для визуального анализа» |
