# 05. AML Detectors For Beginner

## Что такое AML detector

Detector — правило, которое ищет подозрительный паттерн в графе транзакций. Это не доказательство преступления, а сигнал для аналитика.

## Где они находятся

`backend/src/graph/detectors.py`

Тесты:

`backend/tests/test_detectors.py`

## Cycle detector

### Что это

Ищет циклы переводов: деньги проходят через несколько счетов и возвращаются к исходному участнику.

### Зачем нужно

Циклы могут указывать на попытку запутать происхождение средств.

### Что реализовано

Циклы длины 2-6.

### Как проверить

```powershell
cd backend
uv run pytest tests/test_detectors.py
```

## Fan-out detector

### Что это

Ищет ситуацию, когда один отправитель быстро отправляет деньги многим получателям.

### Зачем нужно

Это похоже на smurfing/structuring: дробление суммы на много небольших операций.

## Transit detector

### Что это

Ищет узлы, через которые деньги входят и вскоре выходят дальше.

### Зачем нужно

Транзитные счета могут быть промежуточными звеньями в цепочке отмывания.

## Shared device/IP detector

### Что это

Ищет разные аккаунты, которые используют один device_id или ip_address.

### Важное ограничение

IBM CSV не содержит device/IP. Поэтому detector работает только если такие поля есть во входных данных.
